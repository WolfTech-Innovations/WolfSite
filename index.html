Architecture

Everything needed, nothing extraneous.

Carefully assembled on top of Arch Linux and Budgie to provide immediate day-one utility without configuration fatigue.

[01] Subsystem

Linux Subsystem for Windows (LSW)

Run Windows applications full-screen directly from KibaOS. Zero dual-boot partitioning, zero license key friction, and zero extra hardware needed. Toggle instantly with Super + K.

Workspace 1: Linux Native
Runs lightweight Budgie desktop environment with native Linux apps, browser, shell utilities, and low memory consumption.
Workspace 2: Windows Subsystem (LSW)
Dedicated isolated environment configured on first call. Runs desktop productivity software without requiring manual ISO mounting.
[02] Package Management

kibapkg

Natural-language app management without memorizing obscure flags or commands.

kiba $ kibapkg install firefox
> Resolving package in verified repos...
> Installed Firefox Web Browser.
> Ready in Budgie Application Menu.
[03] Guided Setup

Calamares Installer

Asks one clear question at a time. Plain-language summaries explain every partition change before any bytes are written to disk.

1. Boot Live USB — test hardware compatibility without touching drive
2. Select drive — automatic partition recommendations
3. Confirm changes — installation completes in minutes
[04] Maintenance

Continuous Rolling Release

Built on Arch Linux, updates apply incrementally in the background. No disruptive yearly major version reinstalls or forced reboot popups.

Foundation: Arch Linux x86_64
Desktop: Budgie 10.9 (Wayland)
Display Manager: LightDM / Plymouth boot
